# Thermal Shock Labs

Static site for Thermal Shock Labs (automotive dry ice blasting, laser ablation,
and detailing restoration services in Loveland, OH). Rebuilt from scratch as
plain HTML/CSS/JS — content and photos ported with permission from the
original Squarespace site, no Squarespace template code involved.

## Structure

- `index.html` — home page
- `services.html` — services list
- `about.html` — founder bio / company story
- `contact.html` — contact info
- `assets/css/styles.css` — shared stylesheet
- `assets/js/script.js` — nav toggle + active-link script
- `assets/images/` — photos and logo

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static
file server, e.g.:

```
npx serve .
```
